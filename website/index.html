01 / Capabilities

Everything you need for daily connections, in one workspace.

CxShell brings connections, operations, observation, and assistance together so your desktop serves the task at hand instead of making the task chase windows.

01

Terminal first

SSH, TELNET, RLOGIN, serial, and local Terminal sessions, all in one tabbed workspace.

02

Files and state

SFTP file management, transfer queues, server monitoring, and remote desktop in one session experience.

03

Agent assistance

Access open SSH sessions within clear permission boundaries, with diagnostics, long tasks, approvals, and run summaries.

03 / Technology

A native desktop experience,
an open technical foundation.

CxShell is built with .NET, Avalonia, and AtomUI. It is not a remote tool wrapped in a browser, but a source-available project refined for desktop workflows.

UIAtomUI

Unified desktop controls, themes, and interaction foundations that keep Avalonia pages restrained, clear, and extensible.

APPAvalonia

A cross-platform desktop framework for Windows, macOS, and Linux, preserving the responsiveness a desktop app should have.

CORE.NET 10

Protocols, transfers, monitoring, Agent Runtime, and native bridges organized through MVVM and clear service boundaries.

OPENSource available

Code, documentation, and iteration stay visible on GitHub. Feedback, suggestions, and contributions are welcome within the project license.

04 / Principles

Tools should make complex work feel more orderly.

CxShell grows from real terminal, file transfer, and remote troubleshooting scenarios. AI collaboration has helped explore, build, and iterate on the project, but every boundary, permission model, and interaction choice is guided by real use.
